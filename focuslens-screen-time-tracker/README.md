# FocusLens: see where your screen time really goes

Files from the Zero Cost AI video **"I Built a Free Screen Time Tracker With Claude Code (How It Works)"**.

FocusLens notes which app or website is in front of you every second, then shows a private dashboard
with your focus score, time lost to distractions, deep-work blocks and the habit loops behind them.
Plain Python (no packages to install), Windows only, and your data never leaves your PC.

## Use it on your PC

Copy the whole `example-files/` folder. All the files work together:

| File | What it does |
|---|---|
| [`tracker.py`](example-files/tracker.py) | Every second: active window (program + title) and time since your last input |
| [`rules.py`](example-files/rules.py) | Turns apps and browser tab titles into activities and categories |
| [`analytics.py`](example-files/analytics.py) | Focus score, deep work, context switches, habit triggers |
| [`storage.py`](example-files/storage.py) | Saves sessions in a SQLite file (`screentime.db`) |
| [`app.py`](example-files/app.py) | Starts the tracker and the local dashboard server |
| [`demo.py`](example-files/demo.py) | Generates three weeks of sample data for `--demo` |
| [`static/`](example-files/static) | The dashboard (HTML, CSS, JavaScript) |
| [`start.bat`](example-files/start.bat) | Double-click launcher for the packaged `FocusLens.exe` |

1. Install [Python 3](https://www.python.org/downloads/) (tick "Add Python to PATH").
2. Preview with sample data: `python app.py --demo`
3. Track for real: `python app.py`, then open http://127.0.0.1:8765
4. Optional, build a Windows app:
   ```
   pip install pyinstaller
   python -m PyInstaller --onefile --windowed --name FocusLens --add-data "static;static" app.py
   ```
   Move `dist\FocusLens.exe` into this folder, then put a shortcut to it in your Startup folder
   (Win+R, type `shell:startup`) to track automatically at every login.

- Tracking works on Windows only. On Mac/Linux, `python3 app.py --demo` still shows the dashboard.
- Change categories in the dashboard, or edit `config.json` (created on first run) to add apps and sites.
- Away time: 3 minutes without input. While a browser, video player or call app is playing sound (a course, a video, a meeting), you stay present for up to 4 hours. Change both in the dashboard's settings.
